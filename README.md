# HCL Training Projects

This repository contains the Python data science and machine learning projects
developed during my HCL training. The projects cover data preprocessing,
exploratory data analysis, machine learning, model evaluation, and clustering.

## 📁 Projects

### 1. Loan Defaulter Prediction
A machine learning project focused on predicting loan defaults using borrower
and loan-related information.

**Key concepts:**
- Data preprocessing and cleaning
- Handling categorical and numerical data
- Feature engineering
- Machine learning classification
- Model evaluation
- Confusion matrix and classification metrics
- ROC curve and AUC

**File:**
`Loan Defaulter/loandefaulter.py`

---

### 2. Housing Price Prediction
A machine learning project for predicting housing prices based on property
features.

**Features include:**
- Area
- Bedrooms
- Bathrooms
- Age of property
- Parking spaces
- Floor
- Distance to metro

**Key concepts:**
- Data preprocessing
- Feature encoding
- Train-test split
- Regression modelling
- Model evaluation
- MAE
- MSE
- RMSE
- R² Score

**File:**
`Housing Price Prediction/housing_price_pred.py`

---

### 3. K-Means Clustering
A machine learning project demonstrating unsupervised learning using the
K-Means clustering algorithm.

**Key concepts:**
- Data preprocessing
- Exploratory analysis
- K-Means clustering
- Cluster formation
- Unsupervised machine learning
- Cluster visualization

**File:**
`KMeans/kmeans.py`
